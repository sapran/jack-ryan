# The Jack Ryan analyst pack

Plain markdown, deliberately. Any agentic harness can load these — point yours
at `analyst/role.md` to initialise an analyst, and give it the skills it needs
from `analyst/skills/`.

Nothing here is specific to one model or one vendor. The tools it names are the
`case_*` tools this instance serves over MCP.

- `role.md` — the analyst, its method, and its guardrails.
- `skills/` — the analytic spine: the techniques the role draws on.

These are curated and maintained by hand. Agents do not extend them.
